Ten apps, one button

Put the apps you want in a group and pin it to the taskbar. It takes the space of one icon and opens above it, with all of them inside.

  • Desktop apps, Store apps and browser web apps
  • A folder as a group, or the Control Panel, This PC or the Recycle Bin
  • Groups inside groups, opening beside it like a submenu

With a click, or without one

It opens like any pinned app, or just by resting the mouse on it, and shows up above its icon, on whichever screen it is.

  • Open on hover, off out of the box
  • Right-click: open them all or edit the group
  • By the clock too, with its own icon

Make it yours

Four panel shapes in Windows 11 glass, and each app with its own name, icon and arguments.

  • Grid, row, column or list
  • The group icon: an image, an emoji or its own apps
  • Light or dark, in Spanish, English or Russian

What's new

It updates itself when a new version comes out, if you say yes. These are the last three.

Versions 1.10.0 to 1.10.6 · 17 November 2026

Pin by dragging and give every app its own icon

Each app, its own icon: in the editor you give each app the picture you want, or go back to the automatic one, and web apps installed from Chrome or Edge show their own icon and name instead of the browser's, and now appear in the app list.

Version 1.9.0 · 12 November 2026

Panels show at once even when a drive is asleep

Panels no longer wait: if an app in the group lives on a hard disk that has spun down, a network drive or a USB drive, the panel shows at once with its saved icons and checks the apps afterwards. With an app on a network drive that does not answer, it goes from 22 s to 0.8 s.

Version 1.8.0 · 11 November 2026

Your groups by the clock, and open in an instant

A group by the clock: in the editor, switch on “Also show it by the clock” and the group gets its own icon there. A click opens its panel right by it, and a right-click offers “Open”, “Open all” and “Edit group”.

Ask on GitHub

Is it free?

Yes, all of it. It is open source under the MIT licence: no paid version, no accounts and no ads.

Which versions of Windows does it run on?

Windows 11, and Windows 10 version 1809 or later, 64-bit. On Windows 10 the panel is opaque, like its own menus.

Does it need administrator rights?

No. It installs for your user, not the whole system.

Does it need anything else installed?

Microsoft's .NET 10 Desktop Runtime. If you don't have it, the installer downloads it; the offline installer already carries it inside, for a PC with no internet.

Why does Windows warn about an “unknown publisher”?

Because the installer is not signed with a paid certificate yet. Click More info, then Run anyway. All the code is on GitHub for anyone who wants to check it, and the Microsoft Store version is signed by Microsoft.

Can I install it with WinGet?

Yes. It is in the official WinGet catalogue: winget install Mun1to.TaskbarGroupsFluent installs it and winget upgrade Mun1to.TaskbarGroupsFluent updates it.

Is it on the Microsoft Store?

Yes, since 16 October 2026: apps.microsoft.com. It is the same app, signed by Microsoft and kept up to date by Windows itself. It can be one version behind the installer while Microsoft reviews each update.

How do I pin a group to the taskbar?

Drag the group's icon from the main window onto the taskbar. Or click Pin to taskbar: the app opens the folder with its shortcut highlighted, and you right-click it and choose Pin to taskbar (on Windows 11 it is under Show more options). Windows does not let an app pin itself.

How do I make a group open on hover?

Switch it on in the quick bar at the bottom of the app window, or in the menu of its icon by the clock. It ships switched off: it relies on a small watcher by the clock, which you can turn off from the same places.

Does it work with Start11 or StartAllBack?

Yes. Since version 1.10, open on hover recognises the group by its icon with those taskbars too, even with the taskbar in two rows.

How do I add a taskbar separator?

Click Separator beside Settings in the app. It creates an empty separator entry: pin it like any group. Inside a panel, the Separator button in the group editor splits its apps into parts.

Can I bring my groups from Taskbar Groups or AppGroup?

Yes. Import, in the main window, brings them from Taskbar Groups and from AppGroup. You can also export, import and duplicate your own groups.

Does it update itself?

Yes. When it opens it checks GitHub for a new version and offers it to you: one click downloads it, installs it and reopens the app. The Store version is updated by the Store.

Which languages does it speak?

Spanish, English and Russian. It follows your Windows language, and you can change it in the quick bar of the window.

I wanted this, and it wasn't done right

I wanted my shortcuts packed into a single taskbar button. I looked for it first: something existed, but it still wore the Windows 10 interface, it was awkward to use and nobody was maintaining it.

So I rewrote it from scratch in WPF and .NET 10, with the Windows 11 look and none of the rough edges that made me give up on it the first time. This is that app.

Some code comes from taskbar-groups and its fork pike-beta, both MIT. The Fluent controls are WPF-UI.
